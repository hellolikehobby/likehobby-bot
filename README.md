# Бот-маскоты ЛайкХобби — инструкция по запуску

Бот публикует диалоги маскотов в ваш Telegram-канал: по расписанию (раз в день)
и вручную по команде `/post`.

## Шаг 1. Создать бота в Telegram

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте команду `/newbot`.
3. Придумайте имя бота (например «ЛайкХобби Маскоты») и юзернейм,
   обязательно заканчивающийся на `bot` (например `likehobby_mascots_bot`).
4. BotFather пришлёт **токен** — длинную строку вида
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Сохраните её — это `BOT_TOKEN`, он понадобится на шаге 4.
5. По желанию: отправьте боту фото через `/setuserpic` — это будет
   общая аватарка бота (её увидят в каждом посте рядом с подписью маскота).

## Шаг 2. Добавить бота в канал

1. Откройте ваш Telegram-канал → **Управление каналом** → **Администраторы**.
2. **Добавить администратора** → найдите вашего нового бота по юзернейму.
3. Дайте боту право **«Публикация сообщений»**.

## Шаг 3. Узнать ID канала

1. Перешлите любое сообщение из канала боту **@userinfobot** — он покажет ID.
   Либо, если канал публичный, можно использовать просто `@username_канала`.
2. Сохраните это значение — это `CHANNEL_ID`.

## Шаг 4. Узнать свой личный ID (по желанию, для команды /post)

1. Напишите вашему новому боту в личные сообщения любое сообщение.
2. После первого запуска бота (шаг 6) напишите ему `/whoami` — он пришлёт ваш id.
3. Это `ADMIN_ID` — без него команда `/post` будет доступна всем, кто напишет боту.

## Шаг 5. Разместить код на Railway (бесплатный хостинг)

1. Зайдите на [railway.app](https://railway.app) и зарегистрируйтесь
   (можно через GitHub-аккаунт — если его нет, можно завести за минуту на github.com).
2. Загрузите папку с этим кодом к себе на GitHub одним из способов:
   - через сайт github.com → **New repository** → **uploading an existing file**
     → перетащите все файлы из этой папки.
3. В Railway: **New Project** → **Deploy from GitHub repo** → выберите ваш репозиторий.
4. Railway сам определит `Procfile` и `requirements.txt` и начнёт установку.
5. Зайдите в **Variables** (переменные окружения) вашего проекта в Railway и добавьте:
   - `BOT_TOKEN` = токен из шага 1
   - `CHANNEL_ID` = id канала из шага 3
   - `ADMIN_ID` = ваш id из шага 4 (можно добавить позже)
6. Сохраните — Railway перезапустит бота автоматически.

## Шаг 6. Проверка

1. В логах Railway (вкладка **Deployments** → **View Logs**) должна появиться строка
   `Бот запущен и слушает команды`.
2. Напишите боту в личные сообщения `/post` — в канале должна появиться первая сцена
   (реплики маскотов будут приходить одна за другой с паузой в несколько секунд).
3. Раз в день (в 12:00 по Москве) бот будет публиковать следующую сцену автоматически.

## Как добавить новые диалоги

Откройте файл `dialogues.json` — это просто список сцен. Каждая сцена — это
`title` (название для себя) и `lines` — список реплик, где `mascot` — один из:
`sevryan`, `innokenty`, `yulian`, `veniamin`, `grisha`, а `text` — сама реплика.
Допишите новую сцену по образцу существующих и сохраните файл — на Railway
можно просто отредактировать файл прямо на GitHub, и Railway подхватит изменения
автоматически при следующем деплое.

## Если что-то не работает

Самая частая причина — бот не админ канала или неверный `CHANNEL_ID`.
Проверьте шаги 2 и 3 ещё раз. Логи в Railway (**View Logs**) обычно прямо
показывают текст ошибки.
